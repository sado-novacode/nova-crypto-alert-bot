# ⚡ نوا — ربات هشدار رمزارز (راهنمای فارسی)

ربات تلگرامی که **زبان طبیعی** می‌فهمد. بنویس «بیت‌کوین بالای ۱۰۰ هزار دلار» یا
`btc above 100k` — نوا همان لحظه قانون را می‌سازد، فید زنده بایننس را می‌پرسد و
به محض فعال شدن به تو پیام می‌دهد.

> فایل `README.md` (انگلیسی) برای گیت‌هاب و کارفرماست — دست نزن. این فایل راهنمای خودت است.

## راه‌اندازی روی سیستم خودت (۵ دقیقه)

پیش‌نیاز: **Python 3.11+** از [python.org](https://python.org)

```bash
cd nova-bot

# ۱) توکن ربات: در تلگرام به @BotFather پیام بده -> /newbot -> توکن را کپی کن
cp .env.example .env      # ویندوز: copy .env.example .env
#   فایل .env را باز کن و BOT_TOKEN را جای‌گذاری کن
#   ADMIN_IDS = آیدی عددی خودت (از @userinfobot بپرس)
#   PAYMENT_WALLET = آدرس USDT تو (برای بخش /premium)

# ۲) نصب و اجرا
python -m venv .venv
source .venv/bin/activate        # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

حالا در تلگرام به رباتت پیام بده: «بیت‌کوین بالای ۱۰۰ هزار دلار» 🎉

## چطور امتحانش کنی؟

| بنویس | نتیجه |
|---|---|
| `بیت‌کوین بالای ۱۰۰ هزار دلار` | هشدار قیمت (ارقام فارسی هم می‌فهمد!) |
| `اتریوم زیر 1800` | هشدار قیمت پایین |
| `سولانا ۵٪ تو ۱۵ دقیقه افت کرد` | ریزش سریع |
| `بیت‌کوین ۸ درصد از سقف` | تریلینگ استاپ |
| `پپه حجم ۳ برابر` | جهش حجم |
| `خرید 0.5 اتریوم به قیمت 2200` | ثبت در پورتفوی |
| `واچ سول` | افزودن به واچ‌لیست |

دستورها: `/newalert` `/alerts` `/watch` `/portfolio` `/digest` `/premium` `/lang` `/help`

## درآمدزایی (همان چیزی که به کارفرما می‌گویی)

1. کاربر رایگان: ۵ هشدار فعال.
2. در `/premium` آدرس USDT تو نمایش داده می‌شود (از `.env` تنظیمش کن).
3. کارفرما/کاربر واریز می‌کند → تو کد می‌سازی: `/gencode 10 30` (ده کد ۳۰ روزه)
4. کاربر کد را می‌فرستد → پریمیوم فعال می‌شود. تمام.
